00 · Overview

从「侧栏里的 agent」到「浏览器里的助手」

这一版做四件事：随手可及的入口（浮层）、接管浏览器自己的数据（书签与历史）、替你盯着（页面监控）、越用越懂你（记忆）。后两件共用一个后台底座，记忆再反过来让前三件更准。

  • 提议，再由你应用：批量或不可逆的改动先出方案卡，你点「应用」才执行；和浮层「替换原文」同一个模式。
  • 后台安静，结果可查：监控、整理记忆都在后台跑；只有值得打扰的才发通知，其余进「动态」。
  • 权限按需：书签、历史是可选权限，第一次用到时才问，随时撤销。
入口
浮层

任意网页 ⌘⇧K 或划词唤起，原地多轮对话；需要动手时收成右下角胶囊，侧栏退成任务驾驶舱。

  • 划词浮条（只读 / 可编辑两套）
  • 改写 → 替换原文
  • 转到侧栏，同一个会话
接管
书签与历史

用一句话找回「上周看过的那篇」，整理乱掉的书签栏，按条件清理历史。

  • 可选权限，首次使用时授权
  • 整理 = 方案卡 + 快照还原
  • 历史删除不可逆，单独警示
替你盯着
页面监控

「降到 2000 以下告诉我」——Pie 记住页面上的那个元素，按频率在后台检查，条件满足才通知。

  • 常规检查不调用模型，零 token
  • 条件从不满足变成满足才通知一次
  • 和定时任务合并成「自动化」
越用越懂你
记忆

自动从对话里整理关于你的事实和偏好；每天整理碎片，每月精简一次，总量有上限。

  • 默认无感，用到时一行小字
  • 快速模型按任务挑选相关记忆
  • 设置里随时查看、改、删
后台底座 · 统一的后台任务定时任务、页面监控、记忆整理共用一套调度：按「上次处理到哪」补跑，错过不丢；Chrome 关闭时不运行，下次打开补一次。并发上限共享。
结果出口 · 动态监控触发、定时任务完成、需要你处理的失败，统一进「自动化 → 动态」，带未读点。记忆整理不进动态，避免打扰。

01 · Information architecture

顶栏不加按钮，设置多一组「个性化」

定时任务和页面监控合并成「自动化」，沿用原来的闹钟图标，多一个未读点；设置根页新增「个性化」分组，放记忆、书签与历史、浮层与快捷键，原来的自定义规则也移进来。

  • 顶栏仍是三个功能键：自动化 · 深度研究 · 技能。
  • 未读点只给自动化：颜色沿用「排队中」的黄铜色。
  • 新入口带 NEW 标记：首次打开设置后消失。

03 · Bookmarks & history

书签与历史：找得回、理得清、删得明白

书签和历史都是可选权限，第一次用到时在对话里问；授权后 Pie 多了一组读写工具。查找直接给结果；整理书签先给方案、可还原；删除历史不可逆，单独警示。

  • 读：按关键词、时间、网站搜索书签和历史，直接出结果列表。
  • 小改（加一个书签、改名）：直接做，对话里留一条可撤销记录。
  • 大改（整理、批量移动、删除）：方案卡 → 你点「应用」。

04 · Page monitors

页面监控：说一句「盯住」，剩下的交给后台

在任意网页说「降到 2000 以下告诉我」「有新职位就通知我」，Pie 选中页面上的那个元素，生成一张监控卡。之后按频率在后台检查，条件从不满足变成满足时通知一次。常规检查直接读页面，不调用模型。

  • 条件四种：任何变化 · 数值高于 / 低于 · 出现某段文字 · 列表有新增。
  • 频率：15 分钟 · 1 小时 · 6 小时 · 每天；默认 1 小时，30 天后自动停止。
  • 检查方式：先在后台直接读网页；读不到（要登录、要渲染）再开后台标签页。

05 · Memory

记忆：默认无感，随时可查

Pie 每天把对话里出现的、关于你的事实和偏好整理成短条目，每月精简一次，总量有上限。每次任务开始时，一个快速模型从里面挑出相关的几条带给 Pie。你平时感觉不到它，只有用到时会出现一行小字。

  • 两层：长期记忆（稳定的事实和偏好）＋近期片段（最近的事，未被再次用到会在月度精简时合并或清除）。
  • 不记住：密码、证件号、银行卡；无痕窗口；你排除的网站。
  • 你说了算：「记住……」「忘掉……」立即生效；设置里能查、改、删、清空。
