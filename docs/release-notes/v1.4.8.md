# v1.4.8 — Two local agents stop going missing

## DeepSeek Harness and Pi disappearing from the hand-off list

To find the coding agents installed on your machine, Pie asks your login shell where it looks for commands. That lookup can time out — a slow shell startup is enough — and when it does, Pie falls back to a short list of locations each agent's installer is known to use.

Two agents had the wrong list. DeepSeek Harness pointed at a path its installer never writes to, and Pi had no fallback at all. Every other agent has a second way to be found: an app bundle in your Applications folder, or a location its installer really uses. So when that lookup came up empty, these two were the only ones to vanish outright — gone from Settings and gone from the hand-off card, with nothing to explain why they were there a minute ago.

Both now list the locations their installers actually use, so a slow shell no longer makes them disappear.

## Pie Link 0.4.8

Update from the tray → Check for updates. This is a fix in the background service, so macOS gets it through the in-place updater — no need to download the installer package.
