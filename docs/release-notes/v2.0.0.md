# v2.0.0 — Meet Vailie

Pie is now **Vailie** — same open-source browser agent, new name, new face, and a
rebuilt side panel. This is the largest release since launch: a full design-language
overhaul (Sky Peach), a living brand mark, and a reworked information architecture,
shipped as one update.

## Pie → Vailie

- The extension is now **Vailie · AI Assistant for Chrome** (store listing,
  toolbar, and all six languages). Your data, sessions, API keys, and settings
  carry over untouched — nothing is migrated, nothing is reset.
- New brand mark: a soft gradient blob — silver-grey body, sky-blue welling up
  from below, a peach filament — replaces the old black-and-white icon
  everywhere: toolbar icon, welcome screen, in-page quote button.
- vailie.ai joins pie.chat as a recognized website for the Subscribe bridge.

## A new design language: Sky Peach

- **Borderless UI.** Dividers and outlines are gone; hierarchy now comes from
  background tones, spacing, and soft shadows — across chat, settings, BYOK
  forms, subscriptions, schedules, and every card in between.
- **Sky-blue accent** replaces the old neutral blue-grey for buttons, links,
  selection, and progress. Warnings are now a restrained amber.
- Light and dark themes both re-tuned; theme switching moved to
  **Settings → General** as a three-way toggle (Light / Dark / System).

## The mark is alive

The Vailie mark breathes when idle, stirs while the agent is thinking, churns
while it works on a page, and a peach-forward variant marks recording. Motion
is budgeted — at most two animated instances on screen — and fully disabled
under `prefers-reduced-motion`.

## Rebuilt navigation

- **Top bar, decluttered:** the Vailie mark (top-left) opens a menu hub with
  Session history / Skills / Schedules / Settings. The only other button is
  **＋ New chat** — always one tap. `Cmd/Ctrl+K` and `Cmd/Ctrl+D` still work.
- **Two-form composer:** a slim capsule when idle; focus expands it into the
  full editor with tools, model picker, context ring, and send — everything
  where it was before.
- **Session history** gains a search box and Today / Yesterday / Earlier
  grouping. A pending-confirmation dot now shows on the mark, the history row,
  and the session row.
- **First-run welcome:** a proper onboarding screen — meet Vailie, pick
  Vailie Pro or bring your own key, or just skip and explore.

## Recording, restyled

Recording drops the magenta look for brand blue, with the recording-variant
mark as the live indicator. Skill generation from recordings is unchanged —
finish recording, describe what you want, and the skill is created directly.

## Fixes

- Capsule send button no longer swallows the first click after blur.
- Model picker and context ring stay reachable in paused/failed/archived
  sessions.
- Settings no longer jumps back to the Skills tab after visiting it once.
- Escape closes the menu without also leaving the current view.
- Removed outdated "confirm card" wording from built-in skill instructions;
  destructive tab skills now explicitly ask for your approval in chat before
  acting.
