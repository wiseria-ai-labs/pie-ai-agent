# v2.0.0 — Pie 2.0: In-page overlay, memory, bookmarks & history, page monitors

## Call up Pie on any page

Pie no longer lives only in the side panel. Press **⌘⇧K** (**Ctrl+Shift+K** on Windows and Linux), select text for the floating action bar, or type `pie` and a space in Chrome's address bar to open a lightweight overlay right on the page you're reading.

Select text to run one-click **Translate** or **Rewrite**. When you're editing inside an input or document, Pie proposes the rewrite first and writes it back only when you apply it — preserving the editor's own undo history. You can switch providers and models directly in the overlay footer, handle confirmation cards inline, and hand the conversation off to the side panel at any time without losing context. On pages that can't host overlays (`chrome://`, new-tab pages, PDFs), the same shortcut opens the side panel instead.

## Memory that syncs across your computers

Pie can now remember your preferences and working context across sessions, staying out of the way until it helps and showing a quiet note whenever a reply uses memory. You can inspect, edit, or delete any entry under **Settings → Memory**.

For Pie Pro subscribers, cloud consolidation keeps a single up-to-date memory mirror across your signed-in computers. Sensitive address and contact details are encrypted on your device (AES-256-GCM) before upload and stay redacted by default until you approve an unlock card for the current session. Existing subscribers upgrading to 2.0 see a one-time privacy update prompt before cloud memory sync starts, and consent syncs automatically across signed-in devices.

## Bookmarks & history, handled locally

Ask Pie to track down a page you saw last week, reorganize messy bookmark folders, or clean up specific browsing history.

Both `bookmarks` and `history` are optional permissions requested only the first time you ask for them, and you can review or revoke them anytime under **Settings → Bookmarks & history**. Browsing data is processed locally and never uploaded to Pie servers. Bulk bookmark changes show a preview plan first and keep a 30-day undo snapshot; history deletions show an explicit confirmation card marked irreversible before anything is removed.

## Page monitors & the unified Automation panel

Open any webpage and ask Pie to watch it — a price drop, a text change, or new items appearing in a list. Monitor checks run quietly in the background without using model credits, and Pie sends a system notification as soon as your condition is met.

The top-bar clock icon is now **Automation**, unifying **Activity**, **Monitors**, and **Schedules** into one three-tab view with an unread dot when new results arrive.

## Standalone Pie Account & email code sign-in

Your Pie account now lives in its own **Settings → Account** page, separate from BYOK model configurations. You can sign in with Google or with a one-time email verification code.

## Also in this release

**Stopping a task clears waiting confirmation cards.** Pressing Stop while the agent is waiting on an approval card now aborts the pending request cleanly so the session never gets stuck (#492).

Smaller fixes: entitlement cache now stays in sync across extension contexts so Pie Pro users aren't mistakenly bounced to BYOK setup, overlay locale resolves before first paint, and newly created bookmark folders show their real name in plan previews.
