# v2.0.0 — Pie 2.0：网页浮层、跨设备记忆、书签与历史、页面监控

## 在任意网页随手唤起 Pie

Pie 不再只住在侧栏里。按下 **⌘⇧K**（Windows / Linux 为 **Ctrl+Shift+K**）、划词点浮动条，或在 Chrome 地址栏输入 `pie` 加空格，就能在当前网页原地唤起轻巧浮层，随时开启多轮对话。

划词即可一键**翻译**或**改写**。在可编辑输入框里改写时，Pie 会先给出预览，等你点击应用再写回原文，完整保留编辑器自带的撤销栈。浮层底部可以直接切换供应商和模型、原地处理确认卡，也能随时把整段对话无缝交棒给侧栏继续。遇到不支持浮层的页面（`chrome://`、新标签页、PDF），同一个快捷键会自动打开侧栏。

## 越用越懂你的跨设备记忆

Pie 现在能跨会话记住你的偏好与常用背景——平时安静不打扰，只在回答用到记忆时给一行轻提示；随时可以在「设置 → 记忆」里查看、修改或删除。

Pie Pro 订阅用户支持云端整理与多设备同步，在登录了同一账号的电脑之间保持一份最新的记忆镜像。地址、联系方式等敏感记忆会在本机完成端到端加密（AES-256-GCM）后再同步，平时保持隐藏，只有你在当前会话里点确认卡解锁后模型才能读取。老订阅用户升级到 2.0 后，在开启云端记忆同步前会收到一次隐私条款更新提示，同意状态会自动同步到你的其他设备。

## 本地整理书签与浏览历史

直接用自然语言让 Pie 找回上周看过的页面、整理凌乱的书签夹，或按条件清理浏览历史。

`bookmarks` 和 `history` 均为可选权限，只在你第一次用到时按需申请，随时可在「设置 → 书签与历史」里查看或撤回。书签与历史只在本地处理，不会上传到 Pie 服务器。批量整理书签会先出方案卡供你确认，并保留 30 天可一键撤销的快照；清理历史同样会先弹不可恢复的确认卡，等你确认后才执行。

## 页面监控与全新的「自动化」面板

在任意网页唤起 Pie 说一句「盯住……」（降价、出现指定文字、列表新增等），Pie 就会在后台定期检查并在条件达成时发系统通知——监控检查完全在后台完成，不消耗模型额度。

顶栏原来的定时入口升级为**「自动化」**，把**动态 · 监控 · 定时**收进同一个三段面板，有新结果时右上角会亮起未读提示点。

## 独立的 Pie 账号与邮箱验证码登录

Pie 账号现在从 BYOK 模型配置中独立出来，拥有专属的「设置 → 账号」入口，除了 Google 登录外新增邮箱验证码登录。
