# v1.4.5 — Pie Link 更新得更干净了

这一版都是关于 Pie Link 的 —— 就是那个把 Pie 和你电脑连起来的小程序。以前更新它会留下一堆残局，过程中又什么都看不到，这两件事都修好了。

## 托盘只留一个图标（macOS）

装新的 Pie Link 安装包之后，菜单栏可能出现**两个 Pie Link 图标**：旧的那个还在跑，安装器又起了一个新的，而且两个显示的版本号一样，根本分不出谁是谁。现在 Pie Link 一启动就会请退比自己旧的那份，不管它当初是怎么被打开的。

## 「点此更新」现在真的能点了（macOS）

「检查更新」弹窗里的「点此更新」看着像能点，其实是一行普通文字，唯一的真按钮是「好」—— 你得回到托盘菜单才能真正更新。现在它是正经按钮了：**点此更新** / **稍后**，点下去就直接开始更新。

## 更新过程看得见了

两个平台在更新时都会给出进度，不再一片安静：

- **macOS** —— Pie Link 换新版本时浮一个小窗。
- **Windows** —— 安装包下载时显示进度窗（那是个 ~55 MB 的文件，以前托盘会一声不吭地卡住，直到 UAC 弹出来才有动静）。

## Pie Link 0.4.5

托盘 → 检查更新即可升级。

macOS 用户注意：托盘的更新换的是后台服务，不是 Pie Link 应用本身，所以上面三个修复要随安装包一起生效，不走原地更新。想立刻用上，下载最新的 `.pkg` 装一次即可。
