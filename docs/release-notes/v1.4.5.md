# v1.4.5 — A tidier Pie Link update

This release is all about Pie Link, the small companion app that connects Pie to your machine. Updating it used to leave a mess behind and gave you nothing to look at while it worked. Both are fixed.

## One tray icon, not two (macOS)

Installing a new Pie Link package could leave you with **two Pie Link icons** in the menu bar — the old app kept running while the installer started a fresh one, and both reported the new version, so there was no way to tell them apart. Pie Link now retires any older copy of itself the moment it starts, whichever way it was launched.

## The update button is a button now (macOS)

"Update now" in the *Check for updates* dialog looked clickable but wasn't — it was plain text, and the only real button was OK. You had to go back to the tray menu to actually update. It is a proper button now: **Update now** / **Later**, and it starts the update right there.

## You can see the update happening

Both platforms now show progress while an update runs, instead of going quiet:

- **macOS** — a small window while Pie Link swaps in the new version.
- **Windows** — a progress window while the installer downloads (it is a ~55 MB file; the tray used to sit frozen with no explanation until the UAC prompt appeared).

## Pie Link 0.4.5

Update from the tray → Check for updates.

Note for macOS: the tray updater replaces the background service, not the Pie Link app itself, so the three fixes above arrive with the installer package rather than through an in-place update. Grab the latest `.pkg` if you want them now.
