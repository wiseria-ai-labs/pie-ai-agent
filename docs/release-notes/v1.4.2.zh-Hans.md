# v1.4.2 — 交棒的第一句话按任务来写

把任务交给 Claude、Codex 或 Cursor 时，开场不再是一句固定套话。

## 变更

- **预填的提示词按任务写。** Pie 把工作交给本地 agent 时，App 的输入框（Claude、Codex、Cursor）或 Terminal 的首条指令，现在是一段一到三句的开场白——直接说接下来做什么——取代原先固定的「Read context.md in this directory…」。完整的任务简报仍然写进 `context.md`，开场白只负责把 agent 引到下一步。
- **发送前先看得见。** 交棒确认卡会单独一行展示这段开场白，你清楚 agent 会收到什么再放行。模型没写开场白时，卡片不多出这一行，仍用原来的指引句。

## Pie Link 0.4.2

- 开场白要经 Pie Link 0.4.2 才能送到 agent；旧版 Pie Link 照常可用，只是继续用固定句。在 Pie Link 菜单（macOS）或托盘（Windows）→ 检查更新即可升级。
