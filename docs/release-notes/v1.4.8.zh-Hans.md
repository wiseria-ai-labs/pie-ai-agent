# v1.4.8 — 两个本地 Agent 不再莫名消失

## DeepSeek Harness 和 Pi 有时从交棒列表里不见了

Pie 要知道你机器上装了哪些编程 Agent，得先问你的终端到哪里去找命令。这一步可能超时 —— 终端启动慢一点就够了 —— 一旦问不到，Pie 就退回去查一份清单：每个 Agent 的安装器通常会装到哪。

有两个 Agent 的清单是错的。DeepSeek Harness 记的位置是它的安装器根本不会用的，Pi 干脆没有备用位置。其它 Agent 都有第二条路能被找到：应用程序文件夹里的 app，或者安装器确实会写入的位置。所以每当那次询问落空，就只有这两个会整个消失 —— 设置里没了，交棒卡里也没了，而且没有任何提示告诉你它们刚才明明还在。

现在这两个都记上了各自安装器真正会用的位置，终端慢一点不会再让它们消失。
