# v1.5.1 — 数学公式、模型清单更新、接入 A2Agent

**数学公式能正常显示了。** 模型用 LaTeX 回答时——行内的 `$E=mc^2$` 或 `$$…$$` 公式块——侧栏会渲染成公式，不再是一堆美元符号和反斜杠。

**A2Agent 成为内置供应商。** 一把 A2Agent key，经同一个网关就能用 DeepSeek、Qwen、GLM、Kimi 和 MiniMax 的模型。在设置里像其他供应商一样选它即可。

**模型清单更新到 9 月阵容。** 新增 GPT-6 Astra、Gemini 3.8 Flash、GLM-5.3、Qwen 3.8 Max/Flash，以及 Kimi Code 端点上的 Kimi K3。已下线的模型（Kimi K2.5 与 moonshot-v1）和几个不支持工具调用的 GLM 模型从选择器里移除；如果你之前存的正是其中之一，Pie 不会悄悄替你换成别的模型。视觉与上下文长度标记也按各家官方文档校正了。

**字体随扩展打包。** 侧栏不再从 Google Fonts 加载字体，离线也显示正常，打开时也不会向 Google 发请求。
