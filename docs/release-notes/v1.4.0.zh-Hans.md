# v1.4.0 — Pie Link 登陆 Windows，能自己更新，还能读你正在看的视频

Pie Link 不再只是 Mac 的配件。Windows 有了正式伴侣程序；两边都可以自己更新，不必每次提权重装；把任务交给 Claude / Codex / Cursor 按品牌选，不再拆成两行；打开的 YouTube 或 B 站视频，Pie 可以直接读字幕来总结。

## Pie Link 登陆 Windows

Windows 安装包带托盘应用、开始菜单快捷方式，以及 Mac 上已经有的本机能力：

- **交给本地 Agent** —— Claude、Codex、Cursor、OpenCode、Pi。App 从注册表和微软商店检出；终端 CLI 即使不在默认 PATH 里也能找到。
- **Skill 脚本在本机跑** —— Windows 上以你的账户权限直跑，并明确告知此平台没有沙箱。macOS 默认仍走沙箱。
- **托盘里的诊断** —— 「诊断」和「修复沙箱」，doctor 也懂 Windows（包括本地化的注册表输出）。
- **单实例、品牌图标**，升级失败可以回滚。

## Pie Link 自己更新

不必为每一次 daemon 小版本去提权重装。

- **macOS** —— 真身改放到 `~/.pie/bin`。检查更新会下载已签名的构建并替换，不用输密码。
- **Windows** —— 托盘「检查更新」下载新的安装包（一次 UAC）。
- **如果你是在 1.3.x 装的 Pie Link**，请把本版的安装包装一次。之后就进入自更新通道，后面的版本不应再要求你重装。

## 本地 Agent 按品牌选

设置里以前按形态分行——Claude App、Claude Terminal、Codex App……五个产品排成八行。现在没了。

- **一个品牌一行。** App 或终端装了任一端，这个品牌就能用。
- **确认卡再选形态。** 先选品牌；两端都装了再选这次走 App 还是 Terminal（默认 App）。
- **App 打开时已经带上文件夹和一段草稿提示** —— Claude 和 Codex 走官方深链；Cursor 先开目录再发提示。你看一眼再发送。终端交棒仍然自动开跑。

## 读你正在看的视频

对着打开的 YouTube 或 B 站视频，让 Pie 总结或解释即可。

- 读的是页面自带的字幕 / 转写稿——不下载、不需要 Pie Link、也不走第三方服务。
- 问到画面上是什么时，它会把播放器拖到对应时间，截一帧交给视觉模型。
- 没有字幕就直说，不会从标题编一段「视频内容」。

## Skill 脚本：批准更简单

跑 skill 脚本不再弹出一长串域名和路径清单。确认卡和你已经熟悉的那种一样：skill 名、它做什么、命令和参数。同一个会话里，每个 skill 批一次即可。

脚本也不再被 60 秒掐断，需要跑多久就跑多久。执行过程看得到进度，点停止会杀掉进程。

## 自定义 Provider

- **Responses 或 Chat Completions** —— 按你的网关实际协议选。GPT‑5.x 一类模型在 `/v1/chat/completions` 上拒绝带工具的请求，需要走 Responses。
- **自定义 Provider 的模型可以改、可以删**，以前加进去就卡住。

## 其它

- 文件卡在保存前预览开头几行。按钮改叫 **保存**——它打开的一直是系统保存对话框。
- 中转在流中途报错，不再被当成一次成功的空回复（而且还扣了费）。
- 任务第一步还在等确认卡时，面板或 service worker 挂了，会话会标成失败，你可以重新开始——以前会停在「进行中」，也没有续接。
