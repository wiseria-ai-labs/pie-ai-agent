# v1.4.4 — DeepSeek Harness on Windows

v1.4.3 added DeepSeek Harness as a handoff target on macOS. This release brings it to Windows.

## DeepSeek Harness on Windows

- **Same handoff, same headless run.** Pick DeepSeek Harness on the handoff card and Pie registers the handoff folder as a workspace in `dsh web` (starting it if it isn't running), opens the Web UI in your default browser, and sends the brief into that workspace's session. Local runs can use `dsh --profile headless` as a backend.
- **Detected from the npm install.** Pie finds the `dsh` command on your PATH or at `%APPDATA%\npm\dsh.cmd` — where `npm i -g @deepseek-ai/dsh` puts it. No installer, no registry entry needed.

## Pie Link 0.4.4

- Windows needs Pie Link 0.4.4 for DeepSeek Harness to appear. Update from the tray → Check for updates. macOS gets 0.4.4 too; nothing changes there.
