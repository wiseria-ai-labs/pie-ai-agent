# v100.100.1 — Steadier agent: retries, one tab per task, readable pages

**Provider hiccups no longer kill a task.** When the model's API answers 429, 5xx, drops the connection, times out or returns an empty reply, Pie retries up to 5 times with growing pauses and honours Retry-After. The panel shows "Provider error, retrying 2/5…". If every retry fails, the task pauses instead of failing: history is kept and a **Retry** button continues from the same step.

**The agent stays on its own tab.** A task is bound to the tab it started in. Switching windows or workspaces no longer moves the agent to whatever tab you're looking at. `open_url` now loads pages in that same tab; it opens a new one only when asked (`new_tab`), and new tabs open in the foreground so pages that load content lazily (Google Classroom streams) actually render. If the task's tab is closed, the task pauses and tells you.

**Pages are read as plain text.** `read_page()` returns the page as clean text, about 8,000 characters at a time, with a "Next" pointer for long pages. `query:"§|homework"` returns only the matching lines. The list of clickable elements is capped at 60. Raw-HTML dumps of hundreds of kilobytes are gone, so long tasks keep their context. Only the last 3 page reads are kept in full.

**Navigation waits for the new page.** After a click or `open_url` that changes the page, Pie waits for the new URL/title and for the page to stop loading before reading it. Every page read starts with the tab, URL and title. Old element numbers are invalidated after navigation.

**Friendlier to small local models.** `tabId` can be left out (it means the task's tab), numbers sent as text such as `"1.044214277e+09"` are fixed automatically, and relative links like `/c/123` are resolved.

**Also in this release**
- Line breaks in agent messages render as line breaks.
- Remote MCP servers (Streamable HTTP) with on-demand tool groups; safer error and secret handling for MCP.
- Messages you send while a task runs are no longer lost.
- `click_at` for canvas editors such as Google Docs; `press_key` sends the right key for letter shortcuts.
