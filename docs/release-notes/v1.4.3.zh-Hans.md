# v1.4.3 — 交棒给 DeepSeek Harness

DeepSeek Harness 加入 Claude、Codex、Cursor、OpenCode、Pi 的行列，成为 Pie 可以交棒的本地 agent。先支持 macOS。

## DeepSeek Harness

- **交棒到 Web UI。** 在交棒确认卡选 DeepSeek Harness，Pie 会把交棒目录登记成你 `dsh web` 里的一个 workspace（没开就顺手拉起），打开界面，并把任务简报直接发进该 workspace 的 session。任务立刻开跑，不需要你再手动发送。如果界面原本停在别的 session，点一下新的那条就能看到它在干活。
- **无头运行。** 本地执行可以用 `dsh --profile headless` 做后端：丢一个任务进去，拿结果出来，不开窗口。
- 通过 PATH 里的 `dsh` 命令（或 `~/.local/bin/dsh`）检测。Windows 暂不支持。

## Pie Link 0.4.3

- DeepSeek Harness 要装 Pie Link 0.4.3 才会出现。在 Pie Link 菜单（macOS）→ 检查更新即可。Windows 同样升到 0.4.3，但不含 DeepSeek Harness。
