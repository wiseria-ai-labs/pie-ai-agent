# v1.5.1 — Math, fresher models, and A2Agent

**Math renders properly now.** When a model answers with LaTeX — `$E=mc^2$` inline or a `$$…$$` block — the side panel shows the formula instead of the raw dollar signs and backslashes.

**A2Agent is a built-in provider.** One A2Agent key gets you DeepSeek, Qwen, GLM, Kimi and MiniMax models through a single gateway. Pick it in Settings like any other provider.

**Model lists refreshed to the September lineups.** New entries include GPT-6 Astra, Gemini 3.8 Flash, GLM-5.3, Qwen 3.8 Max/Flash and Kimi K3 on the Kimi Code endpoint. Retired models (Kimi K2.5 and moonshot-v1) and a few GLM models that can't call tools are gone from the picker. If one of them was your saved choice, Pie leaves it as is rather than quietly switching you to a different model. Vision and context-length flags were corrected against each vendor's docs.

**Fonts ship with the extension.** The side panel no longer loads fonts from Google Fonts, so it looks right offline and makes no request to Google when it opens.
