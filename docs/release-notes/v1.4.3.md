# v1.4.3 — Hand off to DeepSeek Harness

DeepSeek Harness joins Claude, Codex, Cursor, OpenCode, and Pi as a local agent Pie can hand work to. macOS first.

## DeepSeek Harness

- **Hand off to the Web UI.** Pick DeepSeek Harness on the handoff card and Pie registers the handoff folder as a workspace in your `dsh web` (starting it if it isn't running), opens the UI, and sends the brief into that workspace's session. The task starts right away — there is no draft to send by hand. If the UI was already open on another session, click the new one to watch it.
- **Run headless.** Local runs can use `dsh --profile headless` as a backend: one task in, result out, no window.
- Detected from the `dsh` command on your PATH (or `~/.local/bin/dsh`). Windows isn't covered yet.

## Pie Link 0.4.3

- Needed for DeepSeek Harness to appear. Update from Pie Link's menu (macOS) → Check for updates. Windows also gets 0.4.3, without DeepSeek Harness.
