# v1.4.2 — Handoffs start with a real first instruction

Handing a task to Claude, Codex, or Cursor no longer opens with a canned line.

## Changes

- **The draft prompt is written for the task.** When Pie hands work to a local agent, the App composer (Claude, Codex, Cursor) or the Terminal's first instruction now carries a short opening — one to three sentences saying what to do next — instead of the fixed "Read context.md in this directory…". The full brief still goes to `context.md`; the opening just points the agent at the next step.
- **You see the opening before you send.** The handoff card shows it on its own line, so you know exactly what the agent will be told. If the model doesn't write one, the card shows nothing extra and the previous pointer line is used.

## Pie Link 0.4.2

- The opening only reaches the agent through Pie Link 0.4.2. Older Pie Link keeps working and keeps using the fixed line. Update from Pie Link's menu (macOS) or tray (Windows) → Check for updates.
