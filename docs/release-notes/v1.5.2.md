# v1.5.2 — Remote MCP servers, steadier clicks, auto-retry

**Connect your own MCP servers.** Settings → MCP servers lets you add a remote server (Streamable HTTP) with optional headers, test the connection and see which tools it offers. The agent loads a server's tools only when a task needs them, and asks you once per chat before it first uses a server. Header values such as tokens are stored encrypted. MCP traffic goes straight from your browser to the server you configured; Pie never sees it.

**Clicks wait for the page to change.** When a click opens a new page or switches a single-page app's view, the agent now waits for the new content to finish loading before it reads the page, so it no longer acts on the page it just left. `open_url` also waits for the page to load.

**Tasks stay on the tab you started from.** A task now binds to the active tab of the side panel's own window at the moment you press send. Switching to another window right after sending no longer moves the task to a tab there.

**Temporary model errors are retried.** Rate limits (429), server errors (5xx) and dropped connections are retried up to three times with backoff, honoring `Retry-After`. Empty model replies are retried too. Daily quota and billing errors are still reported right away.

**Messages you queue during a task are kept.** Instructions sent while the agent was finishing its final reply could get lost; they are now processed in order.

**Interface zoom.** A new slider under Theme in Settings scales the whole side panel from 70% to 150%.

**Refresh models for any provider that lists them.** The refresh button in the model list now works for custom providers and for OpenAI, Zhipu, Bailian, Moonshot and A2Agent, not just OpenRouter.

**Gemini tool calls fixed.** Gemini through a custom OpenAI-compatible provider no longer ends tool turns with an "empty response" error, and the built-in Gemini provider no longer fails with `additionalProperties` or thought-signature errors.

**Line breaks show up.** A single line break in a model reply now renders as a line break instead of being merged into the previous line.

**Lower memory use.** Screenshots are no longer saved into chat history or kept in memory for chats you're not looking at, the panel no longer scans every saved chat on each agent step, and typing no longer re-renders the whole conversation.

Thanks to @ByteMe6, whose reports and pull requests (#458, #461–#467) led to the Gemini, retry, click-navigation, queued-instruction, tab-binding and line-break fixes in this release.
