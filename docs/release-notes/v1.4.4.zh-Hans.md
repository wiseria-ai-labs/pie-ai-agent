# v1.4.4 — Windows 也能交棒给 DeepSeek Harness

v1.4.3 在 macOS 上加入了 DeepSeek Harness，这版把它带到 Windows。

## Windows 上的 DeepSeek Harness

- **同样的交棒、同样的无头运行。** 在交棒确认卡选 DeepSeek Harness，Pie 会把交棒目录登记成 `dsh web` 里的 workspace（没开就顺手拉起），用默认浏览器打开 Web UI，并把任务简报发进该 workspace 的 session。本地执行也可以用 `dsh --profile headless` 做后端。
- **按 npm 安装位置检测。** Pie 通过 PATH 里的 `dsh` 命令或 `%APPDATA%\npm\dsh.cmd`（`npm i -g @deepseek-ai/dsh` 装到的位置）找到它，不需要安装包，也不写注册表。

## Pie Link 0.4.4

- Windows 要升到 Pie Link 0.4.4 才会出现 DeepSeek Harness，托盘 → 检查更新即可。macOS 同样升到 0.4.4，行为不变。
