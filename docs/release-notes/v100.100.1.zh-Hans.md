# v100.100.1 — 更稳的 agent：自动重试、一任务一标签页、页面读成纯文本

**模型接口抽风不再让任务失败。** 遇到 429、5xx、断网、超时或空回复时，Pie 会自动重试最多 5 次，间隔逐步拉长，并遵守 Retry-After。侧栏显示「Provider error, retrying 2/5…」。全部重试失败时任务会暂停而不是失败：历史保留，点 **Retry** 从同一步继续。

**agent 守在自己的标签页上。** 任务绑定在开始时的标签页。你切换窗口或工作区，agent 不会跟着跑到你正在看的标签页。`open_url` 现在在同一个标签页里打开页面，只有明确要求（`new_tab`）才新开；新标签页在前台打开，这样懒加载内容的页面（如 Google Classroom 信息流）才会真正渲染。任务的标签页被关掉时，任务会暂停并提示你。

**页面读成纯文本。** `read_page()` 把页面读成干净的文本，每次约 8000 个字符，长页面末尾给出「Next」续读指引。`query:"§|作业"` 只返回匹配的行。可点击元素列表最多 60 个。动辄几百 KB 的原始 HTML 不再出现，长任务的上下文不会被撑爆；只有最近 3 次页面读取保留全文。

**跳转后等新页面加载完。** 点击或 `open_url` 引起页面变化后，Pie 会等到新的 URL/标题出现、页面不再加载再去读。每次读页面开头都标明标签页、URL 和标题。跳转后旧的元素编号会失效。

**对本地小模型更友好。** `tabId` 可以不填（默认就是任务的标签页），以文本形式发来的数字（如 `"1.044214277e+09"`）会被自动纠正，`/c/123` 这类相对链接会被补全。

**其他更新**
- agent 消息里的单个换行正常显示为换行。
- 支持远程 MCP 服务器（Streamable HTTP），工具按需分组加载；MCP 错误信息与密钥处理更安全。
- 任务运行中发送的消息不再丢失。
- 新增 `click_at`，支持 Google Docs 等画布编辑器；`press_key` 发送字母快捷键时按键正确。
