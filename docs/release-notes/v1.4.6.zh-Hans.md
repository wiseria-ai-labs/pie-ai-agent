# v1.4.6 — Pie Link 不再抢自己的连接点

v1.4.5 发出了托盘和更新的修复，漏了这一个，这版补上。

## 后台服务这次真的只跑一份

Pie Link 的后台服务本该同时只允许一份运行，但 macOS 上这道守卫一直是失效的：第二份会悄悄接管连接点，而第一份还在跑、却谁也够不着它 —— 它仍连着之前就搭上话的那些，对新连接则完全隐身。症状很迷惑：明明有服务活着托盘却显示「未运行」；扩展连的还是你以为已经换掉的那个版本；更新看着成功了，实际什么都没变。

现在服务在占用连接点之前会先探一下有没有人在听：有活的应答，新来的就让位；只找到崩溃后残留的文件，就清掉再接管。

## Pie Link 0.4.6

托盘 → 检查更新即可升级。这一个 macOS 走原地更新就能拿到 —— 它修的是后台服务本身，不是 Pie Link 应用。

v1.4.5 的内容都包含在内：装完不再出现两个托盘图标、「检查更新」弹窗里的**点此更新**是真按钮、两个平台更新时都有进度显示。那三个仍要随安装包生效，macOS 想用上就下载最新的 `.pkg` 装一次。
