# v1.5.2 — 接入远程 MCP server、点击更稳、失败自动重试

**可以接入你自己的 MCP server 了。** 在「设置 → MCP servers」里添加远程 server（Streamable HTTP），可附带请求头，能测试连接并查看它提供哪些工具。只有任务需要时，agent 才加载某个 server 的工具；每个对话首次使用某个 server 前会先问你一次。token 这类请求头值加密存储。MCP 流量从你的浏览器直连你配置的 server，不经过 Pie。

**点击后会等页面变化完成。** 点击打开新页面、或切换单页应用的视图时，agent 会等新内容加载完再读页面，不会再对着刚离开的旧页面操作。`open_url` 也会等页面加载完成。

**任务固定在你发起时的 tab。** 任务现在绑定到按下发送那一刻侧栏所在窗口的当前 tab。发送后马上切到别的窗口，任务也不会跟着跑到那边的 tab 上。

**模型的临时错误会自动重试。** 限流（429）、服务端错误（5xx）和连接中断最多重试三次，带退避并遵守 `Retry-After`；模型回空也会重试。日配额和计费类错误仍然立即报出。

**任务进行中排队的消息不会丢。** 之前在 agent 收尾最后一条回复时发出的指令可能丢失，现在会按顺序处理。

**界面缩放。** 设置里「主题」下方新增滑杆，可把整个侧栏缩放到 70%–150%。

**更多供应商支持刷新模型列表。** 模型列表的刷新按钮现在对自定义供应商以及 OpenAI、智谱、百炼、Moonshot、A2Agent 都可用，不再只限 OpenRouter。

**修复 Gemini 工具调用。** 通过自定义 OpenAI 兼容供应商使用 Gemini 时，工具调用轮次不再报「empty response」；内置 Gemini 供应商也不再因 `additionalProperties` 或 thought signature 报错。

**单个换行正常显示。** 模型回复里的单个换行现在会显示为换行，不再并到上一行。

**内存占用更低。** 截图不再存进对话历史，也不再为你没在看的对话常驻内存；agent 每走一步，侧栏不再扫描全部已存对话；打字时也不再重渲整段对话。

感谢 @ByteMe6：本版的 Gemini、自动重试、点击跳转、排队消息、tab 绑定和换行修复都源自 ByteMe6 提交的问题与 PR（#458、#461–#467）。
