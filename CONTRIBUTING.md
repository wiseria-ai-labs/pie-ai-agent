# Contributing to Pie

Thanks for your interest in Pie! Pie is open source, but **we don't accept
external pull requests**. Pull requests opened here will be closed.

This isn't about code quality. Pie holds your API keys, runs with access to
every page you visit, and can start processes on your machine through Pie Link.
To keep that security boundary tight and the codebase consistent, all code is
written and reviewed by the maintainers.

## How you can help

Your reports shape what we build next, and fixes for reported bugs usually ship
quickly.

- **Bug reports**: [open an issue](https://github.com/wiseria-ai-labs/pie-ai-agent/issues/new)
  with your Pie version (Settings → About), browser version, what you did, what
  you expected, and what happened. Screenshots and console errors help a lot.
- **Feature requests**: open an issue that describes the problem you're trying
  to solve, not only the solution you have in mind.
- **Found a fix?** Describe the root cause and your approach in the issue. We'll
  implement it and credit you in the release notes.

## Building from source

You're welcome to fork Pie and build it yourself under the
